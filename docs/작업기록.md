### 블로그 글 형식 규칙
- 구분선 `━━━━━━━━━━━━━━`과 이모지로 단락을 나눠서, 붙여넣기만 해도 모바일에서 정돈되게
- 한 줄 18자 안팎, 두세 줄마다 빈 줄
- 순서: 제목 → 인사말 → 📌 오늘의 결론 → ①②③ 본문 → 💬 상담 안내 → 서명 → ※ 기준일 안내
- 상담 안내: `📞 전화 상담 【번호】` / `💬 카카오톡 상담 https://pf.kakao.com/_GWFNX/chat` / `📍 【사무소 주소】`
- 태그는 본문이 아니라 발행 설정의 태그 칸에 5개 안팎
- 작성 도구: 아이패드 메모 앱 → 네이버 블로그 앱에 붙여넣기 (안 붙으면 설정 → 앱 → 네이버 블로그 → 다른 앱에서 붙여넣기 허용)

### 재건축 글 예시 숫자 (실제 사례의 금액·시점을 바꾼 것)
- 2002년 2억 취득, 2016년 관리처분인가, 권리가액 8억, 분담금 3.6억, 2026년 33억 양도, 2주택(일반 장특공)
- 인가 전 차익 약 6억, 인가 후 차익 약 21억 (기존 몫 14.5억 / 분담금 몫 6.5억, 분담금 비율 약 31%)
- 장특공: 기존 몫 24년 30%, 분담금 몫 10년 20%
- 예상 세액 약 8.9억(지방소득세 포함), 전부 2002년 취득으로 보면 약 3,200만 원 적게 나옴
- 원본 사례: 구글 드라이브 '채현주 (양도세)' 폴더의 검토요약 문서 (블로그에는 실명·단지명·실제 금액 사용 금지)
